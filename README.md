# Secret Santa (Random Shuffle Approach)
This project assigns each employee a "secret child" following the rules:
1. An employee cannot be their own secret child.
2. They cannot repeat last year's assignment.
3. Each employee has exactly one child, and each child is assigned to exactly one employee (perfect matching).

## Project Structure
- `main.py`: Entry point that orchestrates reading input, creating assignments, and writing output.
- `services/assignment_service.py`: Core logic for generating assignments.
- `services/csv_service.py`: Handles reading/writing CSV files.

## Run 
1.python main.py
